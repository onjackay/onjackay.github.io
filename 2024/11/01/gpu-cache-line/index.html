0x00. Prelogue: 什么是 Cache Line

在 CPU 或者 GPU 的 Cache 层次结构中, Cache Line 是 Cache 的最小单位. 当 CPU 或者 GPU 访问一个内存地址时, 会将这个地址所在的 Cache Line 读取到 Cache 中, 以提高后续访问的速度, 利用了局部性原理. 作为最小单位, Cache Line 不会很大, 通常是 32 字节, 64 字节, 128 字节.

Nvidia GPU 的 Cache 有 L1 Cache 和 L2 Cache. L1 Cache 在 sm 内部, 和 shared memory 共同占用存储: Shared memory 申请的越多, L1 Cache 就会越少. 而 L1 Cache 也主要用于加速 shared memory 的访问.

L2 Cache 则位于 DRAM 下面, 被所有 sm 共享, 用于加速 global memory 的访问.

0x01. Mainloop: L2 Cache Line 大小

我们无法直接访问 GPU 的 L1 Cache 或 L2 Cache, 于是只能间接的通过访存的方式来测量 Cache Line 大小. 对于 L2 Cache, 我们先访问一个内存地址 (在 GPU 上是 Global Memory), 初始时这个地址是不在 Cache 中的, 于是这个这次访存会访问到 Global Memoy, 会有一个较长的延迟, 同时这个地址所在的 Cache Line 会被读取到 Cache 中. 然后, 访问这个地址的相邻地址, 如果这次访存的延迟明显减少, 说明这个地址是在 Cache Line 中的. 重复这个过程, 逐渐增加访存地址的间隔, 直到访存延迟恢复到第一次访存的延迟, 这个间隔就是 Cache Line 大小.
